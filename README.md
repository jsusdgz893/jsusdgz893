### 🛠️ Proyectos destacados

#### 🔐 [Distributed Enigma Machine — ESP32 & Telegram](https://github.com/jsusdgz893)
Implementación históricamente precisa de la máquina Enigma (5 rotores seleccionables, Reflector B, double-stepping auténtico) en MicroPython, distribuida entre dos microcontroladores ESP32 como emisor y receptor.
- Comunicación inalámbrica en tiempo real usando **ESP-NOW**
- Asistente de configuración interactivo y retroalimentación en vivo por pantalla **I2C LCD**
- Entrega automática de mensajes descifrados a un **bot de Telegram** vía Wi-Fi

**Tech:** `MicroPython` `ESP32` `ESP-NOW` `I2C`

#### 🎓 [Professor Evaluation Application](https://github.com/jsusdgz893)
Aplicación nativa de Android que permite a los estudiantes evaluar a sus profesores, con sistema de calificación estructurado, formularios de retroalimentación y visualización de datos de resultados agregados.

**Tech:** `Java` `Kotlin` `Android Studio`
